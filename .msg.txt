fix(dream): write the tool output schema as real JSON Schema

Same error twice: unsupported JSON schema: schema.properties.accepted.required
is not supported on type "boolean".

defineTool converts `parameters` from the authoring dialect but passes
`output.schema` through untouched. My output schema used the dialect form
(required: true on a property) where the host validates real JSON Schema, so the
tool was rejected before any model call.

Moving `required` to the object level and listing the field names there. The test
now asserts both halves: required is on the object, and no property carries its
own required flag. Asserting only the shape I expected is what let the previous
two attempts pass while the host kept refusing the tool.
